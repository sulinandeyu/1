## Windows 已执行检查

运行 `scripts/Analyze-PhotoTriplet.ps1`，输出 `tmp/v8_triplet_metrics.json`。脚本确认三联图可解码，并测量全图、天空、山体、前景和人物区域。

关键结果：旧版成片相对原图全图平均亮度只从 126.44 变为 127.38；天空饱和度从 43.83 变为 46.79；山体亮度从 116.76 变为 119.55。变化集中在轻微提亮和天空增色，山体/前景层次改善有限，支持“单方案且局部目标不足”的审计结论。

参考图的对比和色彩更强，但它不是逐像素目标，也不能作为固定模板。

## 本轮不能伪称通过的项目

Windows 不能运行 Vision、Core ML 和 Core Image iOS 管线，因此没有生成新的 V8 成片。现有 `mastercamera.jpg` 是旧成片，不能冒充 V8 输出。V8 的实际候选图、最终成片和人物真实性仍需新的 iPhone/TestFlight 构建验证。

## 自动测试覆盖

已增加纯决策测试：

- 同场景不同曝光生成不同候选计划。
- 三类候选齐全且不共享同一最终配方。
- 计划强度位于声明范围内。
- 所有人物候选保持硬性人物保护。
- 技术失败候选不能凭高分击败合格候选。

原有测试继续覆盖场景差异、天空差异、蒙版可靠性、识别失败、分割失败、区域统计和人物保护。当前 Windows 缺少 Swift 工具链，本轮未在本机执行这些 Swift 测试。
