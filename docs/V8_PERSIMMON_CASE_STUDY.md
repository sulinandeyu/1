# V8 柿子树案例研究

日期：2026-10-26

## 人工摄影目标

本案例的人工参考目标是：挂果树冠和橙色果实为主要主体；深绿色叶片构成主体环境；灰白天空应保护；石板路用于引导视线；房屋、健身器材、电线及杂物不应获得比主体更强的增强。

这只是本张照片的人工验收目标，不会被硬编码为所有果树、橙色物体或乡村场景的通用规则。

## 当前系统能确认什么

- Vision attention saliency 可以给出“显著区域”，但不等于可靠识别出柿子。
- Core ML 语义分割模型可以尝试产生天空、植被、地面和建筑蒙版。
- Vision 场景分类可能返回 fruit、garden、outdoor 等标签，但真机当次标签和置信度尚未收到。
- 现有模型没有专门的柿子实例分割能力，不能把所有橙色像素简单声明为果实。

因此本轮主体优先级使用：显著性蒙版有效性、覆盖率、主体区域亮度/饱和度/对比与全图的可测分离、场景分类置信度。证据不足时跳过主体局部处理。

## 修复后的主体处理

`PhotoAnalyzer` 对显著主体蒙版测量 `PhotoRegionStatistics`。`PhotoAnalysis.salientSubjectPriorityConfidence` 将蒙版覆盖、视觉分离和语义置信度组合为摄影优先置信度。

`RegionalPixelAdjustment.make(region: .subject, ...)` 只在以下条件成立时生成实际参数：

- 无人脸，避免通用显著性误伤人物。
- 蒙版有效且覆盖率在安全范围内。
- 主体区域统计存在。
- 摄影优先置信度至少 0.54。

主体局部处理可执行有限曝光、高光/阴影、局部对比、自然饱和度和清晰度调整；所有参数受与其他区域相同的硬上限约束。它不会生成物体、替换纹理或按橙色阈值硬选果实。

## 本案例下一轮必须核对

1. `主体蒙版` 是否覆盖挂果树冠/主要果实，而不是天空、房屋或整幅画面。
2. `植被蒙版` 是否覆盖叶片且没有把橙色果实全部吞并。
3. `地面/道路蒙版` 是否跟随石板路，方向和缩放是否正确。
4. 阴天天空是否保持自然灰白，没有青蓝污染。
5. 三个候选的主体亮度、对比与颜色变化是否真正不同。
6. 自动选择是否与人工偏好一致；不一致时记录人工选择，不直接提高全部参数。
