# 小苏相机 V8.1：候选选择修复

日期：2026-10-26

## Build 22 证据

Build 22 成功生成三个候选，但最终选择“自然保守”。最终 RGB MAE 为 2.98%、亮度差异 2.91%、颜色差异 1.03%，平均亮度只增加 0.5%。处理真实发生且没有质量回退，但视觉改善不足。

旧评分主要由技术问题改善和保真分构成。普通显著主体不参与评分，多个语义区域是否协调也没有独立得分；当各候选都处于安全范围时，系统缺少理由奖励真正改善主体和区域关系的方案。

## V8.1 评分组成

新增 `PhotographyAestheticProgressScorer`：

- 主体改善：比较主体相对背景的亮度分离、局部对比、适度颜色分离和实际执行覆盖；
- 区域协调：依据天空、植被、地面、建筑和水面原始状态，检查调整方向、区域参与度与自然幅度；
- 过度处理：亮度或颜色变化超过安全范围会扣分；
- 弱改善惩罚：原图存在明确问题，但问题改善、主体改善和区域协调都很低时扣 14 分。

候选总分不再把“变化最小”等同于“最好”，也不会简单强制选择最强方案。技术质检失败仍然直接拒绝；人物保护仍是硬约束。

三个候选的主体/协调差异也得到增强：

- 自然保守：维持较轻处理；
- 层次增强：对可靠主体增加有限分离，对无主体画面强化安全曲线与区域关系；
- 问题定向：根据实际问题提高主体或整图协调处理，但继续受配方和质检上限约束。

## 新诊断字段

每个候选记录：问题改善、主体改善、区域协调、保真分、弱改善惩罚、区域变化和最终选择理由。人工偏好仍通过 `scripts/Record-PhotographyPreference.ps1` 单独记录，不会把未经选择的数据伪装成用户偏好。
