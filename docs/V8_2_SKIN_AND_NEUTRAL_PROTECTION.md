# 小苏相机 V8.2 肤色与中性色保护

## 保护原则

人物处理以原始照片为身份与肤色基准，不假设一种“标准肤色”，不进行磨皮、美白、祛痘、瘦脸、五官或体型修改。白车、灰墙、灰衣、阴天天空等中性色同样以原图相对关系为基准，不强行校成固定色温。

## 决策层保护

- 检测到人脸时，橙色色相、饱和度和亮度调整全部归零。
- 白平衡限制为温度 ±35 K、色调 ±2 的微调范围。
- 三段色彩分级强度不超过 0.055，暖高光不超过 0.03。
- 人物候选生成后再次执行同样约束，防止候选强度缩放重新放大肤色处理。
- 阴天禁止把天空当蓝天增强；青、蓝饱和度只能保持或降低。
- 大面积低色度或建筑中性色存在时，限制全局白平衡、饱和度、自然饱和度和分离色调。

## 质量检查

`QualityCheckService.colorIntegrity` 在统一的 sRGB 低分辨率采样上计算：

- 中性像素覆盖率。
- 中性色度增量。
- 中性像素红蓝冷暖偏移。
- 中性像素绿偏。
- 中性像素亮度损失。
- 人脸内保守皮肤样本覆盖率。
- 相对于原图的肤色色彩偏移和冷暖偏移。

皮肤蒙版有效时优先使用皮肤蒙版；否则只在人脸框内选取排除高光、深阴影、头发和高色度物体后的保守样本。样本不足时不伪造结论。

新增失败项：

- `skinToneDrift`
- `neutralColorDrift`
- `neutralLuminanceLoss`
- `globalWarmCast`
- `globalGreenCast`

这些项目均为关键失败项。候选被拒绝后，一次性修正会降低白平衡、色彩分级和相关 HSL；人物异常还会将橙色调整归零，并继续保持纹理保护。

## 诊断输出

真机诊断页新增“肤色保护”和“中性色保护”，显示采样覆盖率、色彩偏移、冷暖/绿偏及亮度变化。候选理由中显示肤色/中性色风险，不再只显示像素变化量。

## 尚未验证

当前 Windows 环境不能执行 Vision、Core Image 或加载 iOS 人脸/皮肤蒙版。代码和门禁已实现，但必须用下一 TestFlight 构建重新拍摄自拍、环境人像和白车场景，确认阈值既能阻止偏色，也不会把合理环境光校平。
