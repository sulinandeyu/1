# 小苏相机 V8.1：整图协调模式

日期：2026-10-26

## 触发条件

当可靠人物/显著主体置信度低于执行阈值时，系统明确进入 `globalHarmony`，不会再把高置信度场景标签伪装为主体，也不会因为没有单一主体就退回几乎无变化的轻调。

## 处理原则

整图协调模式只使用现有可靠能力：

- 天空：按高光、亮度和真实天气控制层次，不制造蓝天；
- 植被：按区域亮度、饱和度和纹理余量调整，不统一增绿；
- 地面/道路：按暗部和局部对比建立空间引导；
- 建筑：只有城市/建筑权重占主导时增强结构；小面积背景建筑只保护高光并降低竞争；
- 水面：保留真实反射，不统一染蓝；
- 全局：使用曲线、动态范围、白平衡、自然饱和度和亮度蒙版统一各区域关系。

若有两个以上可靠区域，候选会获得有边界的曲线、局部对比、自然饱和度和亮度蒙版差异。若分割失败，则继续采用已有的安全传统影调降级，并明确记录原因，不宣称完成局部分区修图。

## 人物保护

检测到人物时，整图协调不能越过人物保护：禁止美颜、磨皮、瘦脸、祛痘、面部重建和体型修改；区域蒙版缺少可靠整人物排除时，停用可能误伤人物的语义局部处理。

## 需要真机确认

- 无主体风景是否仍有肉眼可感知、但自然的层次改善；
- 小面积建筑是否不再抢画面；
- 天空、植被和道路之间是否协调；
- 诊断页是否明确显示 `整图协调模式` 与可靠区域数量；
- 质量门是否没有把有效协调错误回退。
