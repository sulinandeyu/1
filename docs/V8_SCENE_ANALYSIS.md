# 小苏相机 V8 场景与摄影问题分析

## 多维输入

现有 `PhotoAnalysis` 同时记录全局亮度、5%–95% 对比范围、高光、阴影、黑白端点、饱和度、RGB、噪声、细节、混合光、光源位置、人脸、人物、显著主体及天空/地面/植被/水面/建筑蒙版和区域统计。

Vision 分类结果具有 `recognized`、`uncertain`、`failed`、`notEvaluated` 状态；Core ML 分割具有 `available`、`noUsableRegion`、`failed`、`notEvaluated` 状态。失败不会被记录成成功。

## 结构化 PhotographyProblemReport

每个问题现在包含：

- `kind`：曝光、高光、阴影、对比、色偏、饱和、噪声或逆光主体。
- `severity`：轻微、中等、明显。
- `affectedRegions`：实际受影响区域。
- `evidence`：来自当前照片测量值的证据。
- `recommendation`：对应摄影处理方向。
- `risk`：过度处理风险。
- `confidence`：由检测严重度和证据生成的有界置信度。

例如，暗部堵塞不再等同于“全图提亮”，而会指向地面、建筑和全局暗部，并明确噪声放大风险。逆光主体只允许可靠整人物或主体蒙版内的摄影曝光协调。

## 降级边界

- 场景分类失败：移除语义 HSL 假设，只保留实测影调和低强度全局处理。
- 语义分割失败：关闭语义天空处理，可继续使用真实亮度蒙版，但不宣称完成语义局部精修。
- 人脸存在但人物蒙版无效：停止场景局部处理和人物局部曝光。
- 蒙版为空、覆盖不足或覆盖近全图：不生成该区域处理计划。

## 当前能力限制

打包 DETR 模型没有独立山体类别。黄土峡谷等区域目前依赖地面/自然语境、显著主体及区域亮度处理，不能把亮度阈值伪称为精确山体分割。
