# Cinematic Imaging Engine V4

V4 是基于真实 iPhone 对比截图进行的质量校准，不把带界面的截图当作原始样片。

## 统一画布约定

1. 使用 EXIF 方向解码后，将 CIImage 平移到零原点。
2. 解码后的完整尺寸是唯一目标画布。
3. 七段影调、三段调色、局部处理与镜头特征输出都必须覆盖目标画布。
4. 最终输出裁切到目标画布，并检查 JPEG 真实像素尺寸。
5. 任何范围缩小或尺寸不匹配都会抛出明确错误，不用黑色填充掩盖。

## 辉光约束

- 以亮度阈值和 0.08 宽度的软过渡隔离高光。
- Bloom 与 Halation 使用不同半径和颜色关系。
- 不再 clamp 高光图像边缘，避免边缘像素被无限复制后形成光团。
- 夜景只有检测到足够高光时启用；室内 Halation 默认关闭。

## 质检与回退

质检相对比较 Original 与 Edited，检查解码尺寸、亮度、暗部瓦片、高光占比和新增青色偏移。真实夜景不会仅因绝对亮度低而失败；只有处理后相较原图明显恶化才触发安全回退。

## 当前验证边界

六张附件是 App 页面截图，不能用于可信的像素级回归。工程已有“样片复测”入口，可从系统照片选择原始文件，并查看 Original、逐阶段结果、Final Edited、差异图与处理日志。
