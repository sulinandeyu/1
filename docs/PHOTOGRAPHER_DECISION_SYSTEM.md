# MasterCamera 摄影决策系统

## 产品原则

MasterCamera 的核心不是固定滤镜，而是把专业摄影师的工作流程结构化：

```text
照片 → 理解照片 → 找问题 → 判断摄影风格 → 制定处理策略 → 分区域处理 → 质量检查 → 保存
```

`Real Photo First` 是不可破坏的边界：保留人物身份、皮肤纹理、真实场景和原始照片；生成式 AI 只能在传统计算摄影无法解决的局部问题上辅助，不能重画整张照片。

## 三层架构

### 1. 视觉理解

当前本地分析包括：

- 亮度均值与亮度分位数动态范围。
- 暗部、高光像素占比。
- RGB 通道平衡、平均饱和度与粗略色偏。
- Vision 人脸区域。
- Vision 整个人物分割蒙版与显著主体蒙版。
- Vision 场景语义标签。

这些结果共同判断人像、逆光人像、风景、夜景、美食、建筑、日落、室内或通用场景。单一指标不能独立决定场景，例如植物造成的绿色占优不能直接视为偏绿。

### 2. 摄影问题诊断

`PhotoProblemDetector` 把视觉指标转换为独立、可追踪的 `PhotoProblemReport`，再交给摄影决策引擎。当前可报告：

- 整体欠曝或过亮。
- 高光溢出风险与暗部堵塞。
- 层次偏平或反差过强。
- 排除合理场景色彩后的偏冷、偏暖、偏绿。
- 饱和度过高与暗部噪点风险。
- 同时存在明亮背景和暗部人物的逆光主体问题。

每个问题包含严重程度和测量证据。没有明确问题时报告为空，决策引擎必须允许不处理，不能为了产生效果强行套用滤镜。

### 3. 摄影风格、策略与确定性图像处理

`PhotographyDecisionEngine` 只在收到画面理解结果和问题报告后判断摄影风格，并生成动态 `AutomaticEditingRecipe`。通用曝光、反差、色偏、噪点调整由问题报告驱动；场景策略负责确定审美边界和局部处理方式。配方可控制：

- 曝光、高光、阴影、亮度、对比度。
- 饱和度、自然饱和度、色温、色调。
- 动态 Tone Curve。
- 降噪、锐化、暗角。
- 人脸区域柔和补光。
- 人物/主体区域柔和补光，避免背景随主体一起被整体提亮。

中性基线不修改曝光；当照片本身已经均衡时，允许“基本不处理”。

### 4. AI 局部增强与分区域处理

当前已加入本地人物和显著主体蒙版。后续只在确有需要时继续加入天空分割、皮肤区域保护、深度估计、光向估计和更精细的局部 Relighting。它们负责提供蒙版或修复局部问题，不负责重新生成照片。

### 5. 质量检查与保存

处理后的照片必须与原片比较高光、暗部、饱和度和整体亮度。质检失败时尝试安全回退；处理或质检失败时不把原图伪装成 AI 成片。用户确认保存后，原图和通过质检的成片才一起写入系统相册。

## 当前场景策略

| 场景 | 动态目标 | 关键处理原则 |
| --- | --- | --- |
| 普通人像 | 自然人像 | 保护肤色与纹理；限制锐化；仅在脸部偏暗时补光 |
| 逆光人像 | 保留环境的逆光人像 | 全局压高光；人物局部补光；避免全图提亮 |
| 风景 | 通透且有层次 | 保护天空/云层；适度打开地面暗部；自然色彩和中间调层次 |
| 夜景 | 保留氛围的电影夜景 | 压灯光高光；克制提暗部；降噪；保留环境冷暖关系 |
| 美食 | 自然诱人的食物色彩 | 校正白平衡；轻微暖色；保留纹理；限制饱和度 |
| 建筑 | 清晰克制的建筑质感 | 强调线条、材质和受控高光；色彩保持克制 |
| 日落/日出 | 保护暖色与太阳高光 | 不做强 HDR；保护暖色渐变和太阳附近高光 |
| 室内 | 色温自然的室内观感 | 修正混合光偏色；温和打开暗部；控制噪点 |
| 通用均衡照片 | 忠实自然 | 不强行提亮或套滤镜，只进行必要处理 |

## 关于“参考摄影大师”

系统参考的是优秀摄影作品中可解释、可测量的摄影原则，例如：

- 主体和背景的亮度关系。
- 高光过渡、暗部密度和中间调层次。
- 冷暖色关系与视觉重心。
- 肤色、天空、植物等记忆色的真实性。
- 局部对比、锐化与观看距离的关系。

不直接复制某位摄影师作品，不使用固定“大师 LUT”，也不以模仿个人风格替代对当前照片的判断。

## 后续校准方式

1. 建立覆盖各类场景的固定原片样张集。
2. 保存每张照片的分析结果、最终配方和质检结果。
3. 对比原图与成片的高光、阴影、饱和度、肤色和噪点指标。
4. 由人工盲评自然度、主体突出程度和是否过度处理。
5. 只有在多张样片上稳定改善的规则才能进入默认版本。
