# MasterCamera 成片质量真机验证

本清单用于 Phase 2.1 的固定样片回归。每次版本使用同一台 iPhone、同一机位和尽量一致的光线拍摄，分别保留 `Original` 与 `AI Edited`，不要使用截图代替原始照片。

## 必测场景

1. 正常光线自拍：检查肤色、皮肤纹理、眼睛与头发细节、背景层次。
2. 逆光自拍：检查天空高光、人脸补光、人物边缘和背景协调性。
3. 阴天户外人像：检查脸部灰暗、色温、自然红润程度和衣物细节。
4. 夜间街头：检查灯牌高光、暗部噪点、冷暖关系及夜晚氛围。
5. 室内暖色灯光：检查黄/绿偏色、人物肤色、暗部噪点和混合光源。
6. 普通风景：检查云层、天空、植物绿色、远近层次和 HDR 光晕。
7. 原片已经良好：检查系统是否保持克制，没有强行加重滤镜。

## 每张照片检查项

- 在预览页切换“原图 / AI 成片”，并长按成片再次核对同一像素内容。
- 展开诊断信息，记录场景、问题、曲线类型/强度、色彩分级、局部补光、降噪、锐化和颗粒参数。
- 放大检查人物边缘、天空边缘、头发、皮肤、文字和灯光，确认没有光圈、蜡像、白边或伪影。
- 在系统相册的信息页确认两张照片均为原始分辨率；Original 与 AI Edited 文件名应可区分。
- 记录从按下快门到预览出现的等待时间以及是否发生卡顿、内存警告或闪退。

## 验收原则

- 有明确曝光、色彩或层次问题的原片，AI Edited 必须有肉眼可见且合理的改善。
- 人物身份、五官、脸型与真实皮肤纹理不能改变。
- 原片已经优秀时允许差异较小，但不得因追求差异破坏照片。
- 任何一类场景出现系统性偏色、过度 HDR、死黑、死白或边缘伪影，都应保留样片并回到对应策略校准，不能用另一层固定滤镜掩盖。
