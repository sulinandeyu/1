## 必测场景

| 场景 | 主要检查点 | 通过标准 |
|---|---|---|
| 晴朗天空与人物 | 天空、人物、山地/地面分离 | 天空不过蓝；人物外貌不变；地面层次自然 |
| 阴天风景 | 云层与地面层次 | 不统一染青；云层与前景均有自然层次 |
| 室内 | 混合色温、灯具高光、暗部 | 暖光真实；灯具不溢出；家具不脏灰 |
| 城市夜景 | 点光源、高光、暗部、噪声 | 不提亮成白天；灯光颜色保留；暗部不死黑 |
| 植被/乡间道路 | 植被、道路、纵深 | 不统一增黄或增绿；道路和植被参数来自各自区域 |
| 逆光人物 | 人物/背景光比 | 只调整整个人物；脸部结构和纹理不变 |
| 普通旅行照 | 主体与环境关系 | 主体更明确但无明显滤镜感 |
| 已经很好看的原图 | 克制处理 | 允许接近原图，不为差异破坏画质 |

## 日志核对

- [ ] 场景状态明确为 recognized、uncertain 或 failed。
- [ ] 分割状态明确为 available、noUsableRegion 或 failed。
- [ ] 每个区域有覆盖率；空蒙版不得显示“已执行”。

- [ ] 处理失败时没有 AI 成片，原图仍保留。

## 人物保护

- [ ] 五官位置、脸型、身体比例没有改变。
- [ ] 没有磨皮、美白、祛痘、祛斑或生成式修复。
- [ ] 皮肤、头发和衣物纹理没有被涂抹。
- [ ] 局部蒙版没有在人物边缘产生光晕或颜色污染。
- [ ] 人脸区域与背景的变化差没有异常放大。
