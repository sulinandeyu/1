# 小苏相机 V8 候选评价机制

## 评价信号

每个低分辨率候选都执行真实 Core Image 渲染，并由 `QualityCheckService` 检查：

- 画布尺寸、亮度、对比、高光和阴影
- 饱和度、异常偏色、纯白扩张
- 噪声放大和细节过度
- 人脸与背景变化差、皮肤纹理比
- 蒙版边界突变
- 计划区域是否真正执行

随后根据原始 `PhotographyProblemReport` 计算问题改善度。例如欠曝检查亮度是否向正确方向移动，高光问题检查高光占比是否降低，平淡场景检查对比跨度是否合理增加。

## 分区像素证据

天空、地面、植被、水面、建筑、人物和显著主体的有效蒙版会记录：

- 蒙版覆盖率
- 区域平均亮度变化
- 区域颜色变化
- 区域变化像素比例

这些数据证明局部节点实际改变了哪些像素，但不会单独被解释为“更好看”。

## 选择规则

评分组合技术质量、问题改善和真实性保留。技术失败的候选不能仅凭高改善分超过合格候选；若全部候选被拒绝，优先回到自然保守候选并接受完整分辨率质检，仍失败则明确终止，不把异常结果标记为 AI 成片。

像素差异大小不作为单一优化目标。未测得改善时改善分为 0，不能因为渲染完成就获得默认改善分；缺少对应区域指标时也不得虚构局部改善。没有明显问题的优质原图不需要争取“问题改善分”，候选主要按技术质量与保真度选择。

2026-10-25 复核修正：旧实现的方向归一化以 0.5 为零点，导致完全未变化的候选也会获得 50% 改善分；区域指标缺失时还会获得 35% 默认分。现已改为只奖励有实测、方向正确的改善，并为该边界加入自动测试。

## 可解释记录

App 的“像素与处理链诊断”现在包含候选名称、状态、分数、问题改善、保真、区域变化、耗时、失败原因和最终选择标记。
