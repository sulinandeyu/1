# 小苏相机 V8 编辑计划

## PhotographyEditPlan

每个候选包含 `id`、摄影意图、实际 `AutomaticEditingRecipe`、形成理由和若干 `PhotographyPlannedAdjustment`。每项调整记录：

- 目标区域与调整类型
- 实际强度与允许范围
- 置信度和证据原因
- 预期摄影效果
- 风险与降级行为

## 候选不是固定 LUT

三个候选都从 `PhotographyDecisionEngine` 对当前照片计算出的配方开始：

1. 自然保守：按问题严重度缩放当前配方，限制局部对比、色彩分级和镜头效果。
2. 层次增强：仅在实测层次不足或空间深度不足时增强曲线、中间调分离和局部对比；高反差照片反而降低对比。
3. 问题定向：针对欠曝、过曝、高光、暗部、平淡对比、强反差、过饱和、噪声和逆光主体分别计算参数。

同一场景的亮照片与暗照片会得到不同曝光方向；同一“天空”场景是否调整天空仍取决于高光、饱和度、蒙版和分割状态。

## 人物硬约束

三个候选生成后都重新执行：

- `faceExposureEV = 0`
- 没有可靠人物蒙版时 `subjectExposureEV = 0`
- 保持高肤质保护，限制锐化、降噪和局部对比
- 橙色明度归零，橙色饱和度限制在极小范围
- 禁止几何、生成式和面部修复操作

## 性能边界

候选预览最长边为 640 像素，默认预算 3.2 秒；至少评估两个候选后如超时，其余候选明确标记为 `skipped`。只对选中的计划进行完整分辨率渲染，最终质检最多触发一次修正。
