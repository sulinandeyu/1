# 颜色与白平衡规则

## PT-COLOR-001：可靠中性色证据优先于全图 RGB 均值

- 来源：APPLE-CI-02、PAPER-CC-01、PAPER-CC-02、PAPER-CC-03。
- 问题：肤色、橙色果实、蓝天或植被会改变全图通道均值，但不一定代表照明色偏。
- 适用：画面中存在足够数量、亮度不过曝/欠曝、低色度且非人脸的候选中性色像素。
- 不适用：纯色场景、舞台灯、日落、蓝调时刻、低覆盖率或混合光强。
- 测量：中性色覆盖率、样本数、R/G/B 均值、R-B 偏差、G-(R+B)/2 偏差、混合光分数、人脸排除情况。
- 方法：仅在中性色置信度达到阈值时诊断全局色偏；由偏差连续计算有限温度/色调修正，并用混合光保护权重衰减。
- 副作用：错误中性假设会让肤色偏橙红、白色染黄/绿，或破坏现场暖光。
- 验证：中性色偏差减小；源图肤色色相和现场光氛围不被强制归零。

当前代码中的覆盖率、色度和偏差阈值是“是否允许尝试校正”的保守工程门槛，并不是 Adobe/Apple 提供的专业标准值。它们必须由真实灰/白物体、人物和混合光样片继续校准；在此之前，低置信度一律跳过比强制校正更可靠。

## PT-COLOR-002：混合光保留与保守降级

- 来源：PAPER-CC-01、APPLE-CI-02。
- 问题：单一全局白平衡无法同时校正不同光源区域。
- 适用：暖/冷像素同时占有可测比例，或空间亮度/颜色关系显示多个光源。
- 不适用：有可靠单一照明估计时无需额外衰减。
- 测量：混合光分数、局部颜色统计、人物覆盖率。
- 方法：降低全局温度/色调幅度；只有可靠局部蒙版时才做区域校正，否则保留现场光。
- 副作用：过度中和会消除夜景与室内暖光氛围。
- 验证：白色物体不新增色偏，各区域相对冷暖关系仍可信。

## PT-COLOR-003：色彩空间与参数单位不可混用

- 来源：APPLE-CI-01、APPLE-CI-02。
- 问题：在线性 RGB 中直接做感知 HSL，或把 Lightroom -100…100 滑块传给 Core Image，会产生错误幅度。
- 适用：所有渲染路径。
- 方法：Core Image 使用明确的扩展线性 sRGB 工作空间和 sRGB 输出；感知 HSL 在编码 sRGB 中计算后再返回线性工作空间；温度/色调使用源白点与目标白点语义。
- 副作用：重复转换、错误 gamma 或单位会造成肤色与白色漂移。
- 验证：中性色往返误差、HSL 单元测试、最终输出 ICC/色彩空间检查。
