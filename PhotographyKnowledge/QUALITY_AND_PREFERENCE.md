# 质量评价与人工偏好

## PT-QA-001：技术安全与审美偏好分层

- 来源：PAPER-IQA-01、PAPER-IQA-02。
- 问题：像素变化率只能证明发生变化，不能证明更美；技术指标也不能完全代表审美。
- 方法：第一层检查裁切、死黑、色偏、噪声、过锐、蒙版边界和人物保护；第二层检查原始摄影问题是否改善；第三层保留 A/B/C/原图/都不好的人工作品偏好。
- 不适用：没有人工标注时不得把自动得分称为真实用户偏好。
- 副作用：只奖励低风险会永远选择最弱候选；只奖励变化会制造夸张效果。
- 验证：记录候选参数、技术分、问题改善分与人工选择，分开统计。

## PT-QA-002：质量回退必须可解释

- 方法：回退需记录触发指标、阈值、被拒候选和最终文件标识；禁止静默返回原图并显示成功。
- 验证：诊断页和日志能从最终文件追溯到实际参数、渲染与质量结论。

## PT-QA-003：强影调的结果反馈安全修正

- 来源：`PT-QA-001/002`、`ADOBE-TONE-01/02`、`ADOBE-MASK-01`；Build 31 M/R3-I 的真实质检失败证据。
- 解决问题：强影调验证可以接近摄影目标，但全局压暗与全范围局部压暗叠加后造成暗部裁切、中性色亮度损失和蒙版边界伪影。
- 输入测量：`QualityCheckService` 的 `tooHarsh`、阴影/黑位异常、中性色亮度与色度偏移、区域边界问题及真实区域影响；不得由预设名称触发。
- 适用条件：仅 M/R3 隔离诊断；第一次真实 Core Image 渲染和质检均已完成，并存在可修正的明确问题。
- 不适用条件：渲染失败、质检没有可修正证据，或修正候选没有减少问题/改善状态。
- 计算方法：保持原始强影调意图，但有界收回全局反差和中间调压缩，按实测中性色损失恢复有限曝光；把局部调整限制到中间亮度范围、增加羽化、减少区域 EV/曲线幅度并对暗部增加保护。重新真实渲染和质检；不修改任何质检阈值，只有状态或问题数量改善时才采用。
- 副作用：修正可能降低与目标图的数值拟合度，或仍不足以消除复杂蒙版产生的伪影。
- 验证：保留修正前后完整参数、图片和质检；检查地面/建筑黑位、白车和中性色、天空端点、蒙版边缘及人工观感。Windows 参数测试不能替代 Core Image/iPhone 验收。

## PT-QA-004：参数生命周期审计

- 来源：`PT-QA-001/002` 与 Build 27–32 诊断中“计划存在但实际变化过弱”的执行证据。
- 解决问题：求解参数在可靠性、安全、颜色、人物保护或产品边界阶段被覆盖后，诊断只显示最终值，无法定位损失发生在哪一层。
- 输入测量：求解器输出及每个限幅阶段前后的同一 `AutomaticEditingRecipe`。
- 适用条件：B/D/E 的决策与诊断；生命周期只记录，不产生新参数。
- 不适用条件：不得把记录中的计划值冒充渲染值。
- 计算方法：依次记录 `solverOutput → analysisReliabilityLimits → problemSafetyLimits → colorIntegrityGuards → portraitProtection → finalProductBounds`，只列真实变化字段；最终渲染和渲染后测量仍分别记录。
- 副作用：诊断 JSON 增大，但不增加图像处理时间。
- 验证：自动测试确认阶段顺序和最终配方；诊断 ZIP 能区分 planned、limited、rendered、measured。
