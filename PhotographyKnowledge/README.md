# 小苏相机摄影知识库

本目录把可核验的摄影技术转换为可检索的工程规则。它不是滤镜、LUT 或 Lightroom 滑块预设库，也不以“人像/风景/建筑”等标签直接选择固定配方。

## 使用流程

`当前照片测量 → 摄影问题 → 适用规则 → 动态参数 → Core Image/自定义模块 → 质量与人物保护检查`

每条规则至少包含：来源、解决的问题、适用条件、不适用条件、所需测量、求解方法、安全边界、副作用和验证方法。运行时通过规则 ID 把参数证据与本文档关联。

## 证据等级

- A：平台/软件官方技术文档或同行评审论文，并已有代码与测试映射。
- B：可靠来源且已有设计映射，但仍待 iPhone 实拍验证。
- C：项目经验性假设，仅可做保守候选，不得写成成熟摄影规律。

目前多数规则为 A/B；iPhone 视觉验收仍是独立状态，不因文档或自动测试通过而自动成立。

## 摄影参考规则

- `PT-REF-001` 参考适用性门控（来源：`DATA-COMMONS-01`、`PAPER-IQA-01`）：输入当前照片的连续影调、色彩、中性色和语义辅助证据；只有逐文件许可范围与相似置信度同时满足才允许进入目标校准。不适用时返回原测量驱动求解器。副作用是小型参考集可能检索不足；验证方法为跨集检索、近重复审计和真机 A/B/C。
- `PT-REF-002` 参考目标有限校准（来源：`ADOBE-TONE-01/02`、`ADOBE-MASK-01`、`PAPER-IQA-01`）：参考仅能以小权重调整亮度、动态范围、阴影、高光、饱和度和局部关系目标，禁止复制白平衡、HSL、曲线或直方图。输入必须包含当前照片测量和 `PT-REF-001` 结果。副作用是变化可能较小；验证方法为参数证据、Core Image 回执、质检与人工盲测。
- `PT-REF-003` 验证路径隔离（来源：`PAPER-IQA-01/02`，以及本项目数据授权边界）：A 原图、B 当前正式算法、C 参考校准候选只在诊断导入启用，C 不替换 B。副作用是诊断处理时间和内存增加；验证方法为预览名称、处理阶段日志和正式拍照未执行记录。
- `PT-UNDERSTANDING-001`、`PT-AESTHETIC-001/002/003` 见 [逐图视觉理解与摄影审美规划](AESTHETIC_PLANNING.md)：它们分别约束语义证据边界、视觉层级、区域颜色协调与摄影氛围保护。
- `PT-AESTHETIC-009` 当前照片实测关系驱动的影调意图（来源：`ADOBE-TONE-01`、`ADOBE-MASK-01`，并受 `PT-UNDERSTANDING-001` 约束）：输入必须是当前照片中可用地面与植被蒙版的覆盖率、可靠度、区域亮度、区域饱和度、噪声余量及端点风险；只有低饱和区域在亮度上明显压过另一可靠且颜色更丰富的区域时，才生成“降低前者相对亮度”的关系目标。它不适用于蒙版无效、区域饱和关系不足、暗部噪声高或人物保护证据不足的照片；不得读取场景名称、参考目标图或固定秋季参数。副作用是技术上成立的层级假设未必符合人的审美偏好，因此状态必须保持 `human-review-required`，不能自动宣称专业审美通过。验证方法为同场景标签但不同实际区域关系的参数方向测试、真实区域渲染复测、跨场景回归及盲测。
- `PT-AESTHETIC-010` 实测目标空间与真实渲染差异门控（来源：`ADOBE-TONE-01/02`、`ADOBE-MASK-01`、`APPLE-CI-01`、`PAPER-IQA-01/02`）：输入为当前照片可靠区域的亮度、颜色、覆盖率、噪声和端点余量，并分别生成连续性、空间层级和克制深度的区域目标；名称不提供参数，区域目标必须从本图测量重算。三张候选完成真实 Core Image 渲染后，必须比较 D/E1/E2 的全图 RGB MAE、变化像素率及区域亮度/颜色差异；若至少两组没有形成实质差异，或 E1/E2 仍高度相似，标记 `candidate_generation_failed`，不得宣称成功生成三种摄影表达。它不适用于缺少完整同源渲染或人物保护证据不足的情况。副作用是更强的目标探索可能增加暗部、端点和蒙版边界风险，仍须原有质检和人工盲测。验证方法为 Build 34 近似候选回归、Apple Core Image 像素测试、七图跨场景取证和人工评价。
- `PT-AESTHETIC-011` 实测冷灰环境与暖色重点关系（来源：`ADOBE-TONE-01/02`、`ADOBE-MASK-01`、`APPLE-CI-01`，本地未授权案例仅用于失败方向观察）：产品方向固定为真实、克制的冷调电影感，但调整幅度必须来自当前照片的全局/区域亮度、饱和度、暖色占比、中性色、噪声、端点和蒙版质量。D、E1、E2 分别求解平衡、空间层级和克制暗调，不读取目标 T、反求参数或场景预设。人物证据存在时显著衰减颜色分离并继续执行源图相对肤色/纹理保护。验证方法见 [冷调电影感工程验收标准](COOL_CINEMATIC_STANDARD.md)。
- `PT-QA-005` 中性亮度损失的语义归因（来源：`ADOBE-MASK-01`、`APPLE-CI-01`，并延续 `PT-COLOR-003` 的源图相对保护）：输入为源图中性色样本、人物/显著主体/建筑保护蒙版、实际执行的有意影调区域以及处理前后区域像素。白车、人物、显著主体与建筑等保护中性色仍使用原有亮度损失阈值；道路等明确要求压暗的区域不与它们合并求平均，而继续接受区域暗部裁切、纹理能量、色偏和蒙版边缘检查。它不适用于空蒙版、未执行的计划或无法追踪到实际渲染的参数；这些情况必须继续按保护样本处理。副作用是错误蒙版可能错误归因，因此保护蒙版优先级高于影调蒙版。验证方法为逐像素归因热图、区域覆盖/亮度位移记录、原阈值回归以及真实 Core Image 输出复核。
- `PT-PREF-001` 隔离样本上的人工摄影偏好校准（来源：`PAPER-IQA-01/02`、`PT-QA-001`）：输入为同源原图、真实候选、技术状态和双盲人工选择；开发/盲测按原图哈希隔离。它不产生调色参数，不允许失败候选绕过技术门，也不允许把最接近原图、自动总分或参考目标 T 当成偏好真值。副作用是少量评价存在主观分歧，因此排序器必须提供不确定性与弃权。验证方法为跨场景重复盲测、评价者一致性、留出集成对准确率和真实 iPhone 成片复核。
- `PT-PREF-002` 候选生成/选择失败分离（来源：`PT-PREF-001`、`PT-QA-001`）：输入为同源 D/E1/E2 的真实渲染、技术状态、区域变化和人工盲测。缺真实图或缺人工标签时保持证据不完整/待评价；全部技术安全候选被判差才是 `candidate_generation_failed`，存在人工支持候选但自动未选中才是 `candidate_selection_failed`。它不产生调色参数，也不允许用工程代理分数补写人工结论。验证方法为契约测试、诊断 ZIP 状态和七图隔离盲测。
- `PT-INVERSE-001/002/003` 见 [专业摄影参数逆向求解](INVERSE_PARAMETER_SOLVING.md)：仅用于同源 A/T 的研发验证，分别约束配准、渲染器内反求以及表达能力/安全范围分离；反求参数不得变成场景预设。

## 学习型增强准入规则

- `PT-LEARN-001` 学习模型许可与数据血缘门控（来源：`PAPER-HDRNET-01`、`MODEL-DEEPLPF-01`、`DATA-FIVEK-01`）：输入代码许可、权重来源、训练数据许可、目标分发范围和模型校验值；只有代码、权重和训练数据都允许当前用途时，模型才可进入 App 构建。不适用于“论文公开但权重或训练数据不明”的模型。副作用是可用模型范围缩小；验证方法为逐资产许可记录、构建资源审计和无受限权重的 TestFlight 包检查。
- `PT-LEARN-002` 源图相对安全门（来源：`PAPER-HDRNET-01`、`PT-PORTRAIT-001`、`PT-COLOR-003`）：输入原图/模型结果的高光与暗部裁切、中性色位移、人物/皮肤蒙版和局部变化；模型输出先作为 C 候选，暗部、高光、中性色或人物真实性超限时拒绝，不因像素变化大而通过。不适用于缺少可比色彩空间或方向不一致的图片。副作用是部分有审美价值的激进结果会被拦截；验证方法为同色彩空间指标、100% 观察和人物盲测。
- `PT-LEARN-003` 语义证据门控与未知降级（来源：`APPLE-VISION-04`、`APPLE-COREML-02`、`MODEL-DEEPLAB-01`）：输入类别、像素置信度、覆盖率、边界质量和误检检查；可靠蒙版只用于保护或限制局部变换，未支持类别统一输出未知并降级到亮度区域/全图协调。不适用于把背景类解释成天空、建筑、道路或植被。副作用是局部能力不足时变化更保守；验证方法为真实蒙版叠加图、覆盖率、误检样本和 iPhone 性能记录。
- `PT-TRAIN-001` 配对血缘与权利门控（来源：`DATA-FIVEK-01`、`DATA-UNSPLASH-01`、`DATA-PAIRED-REVIEW-01`）：输入同底片声明、原图/目标哈希、配准证据、专家身份、编辑意图、商业训练权和模型分发权；任一缺失时只能拒绝或降为 `pipeline_smoke_only`。不适用于把不同帧、不同取景、优秀单图或旧算法输出冒充专家配对。副作用是当前可训练数量为零；验证方法为导入器拒绝测试、逐对人工复核和许可清单。
- `PT-TRAIN-002` 有界双边残差学习（来源：`PAPER-HDRNET-01`、`MODEL-HDRNET-01`）：低分辨率网络基于当前图预测小型双边仿射系数网格，恒等系数加有界残差后边缘引导切片到原图像素；输入是当前图及可缺省语义，输出不是无约束重建。适用于合法专家配对充足后的学习型 C2；不适用于五张旧算法目标冒充产品训练。副作用是网格过小可能欠拟合、切片算子可能增加 Core ML/Metal 集成成本；验证方法为恒等初始化、网格尺寸、实际 GPU 训练、局部变换图和 iPhone 对齐。
- `PT-TRAIN-003` 人物/中性色/细节训练约束与独立验收（来源：`PT-PORTRAIT-001`、`PT-COLOR-003`、`PAPER-IQA-01`）：输入人物蒙版内肤色/纹理、中性色 Lab、两端裁切、饱和溢出、光晕和严格 train/validation/test；训练损失只限制真实内容，最终仍需未参与训练的手机照片盲测。不适用于用损失下降或技术门通过代替审美验收。副作用是保护权重过强可能减弱合理摄影调整；验证方法为源图相对指标、人物 100% 检查、随机盲测和问题标签。
