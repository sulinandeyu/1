# 小苏相机冷调电影感工程验收标准

本标准约束内部 D/E1/E2 诊断候选的摄影方向，不是 LUT、滤镜或固定参数表。正式 B、普通拍照与原图保存不受影响。所有实际幅度由当前照片测量求解，并受人物、中性色、端点、噪声和蒙版质量保护。

## 统一方向

- 环境保持自然冷灰与低杂色，不把阴天强行染成青蓝。
- 当前照片已存在的暖色重点可获得适度色彩分离，不新增颜色或物体。
- 暗部建立情绪和空间层次，但保留必要纹理，不产生死黑。
- 高光柔和且不过曝；白车、白墙、灰建筑等中性色保持干净。
- 禁止假 HDR、统一冷色覆盖、明显蒙版光晕、生成式重绘和任何人物美颜。

## 三个诊断目标

| 候选 | 摄影意图 | 主要可变关系 |
|---|---|---|
| D | 平衡型冷调电影感 | 适度降低明亮低色度环境，保留可读暗部，以实测暖色为重点并维持中性色 |
| E1 | 空间层级更强 | 扩大可靠地面/植被或主体/背景的亮度关系，增加受噪声约束的局部层次 |
| E2 | 克制暗调更深 | 压缩可恢复中间调与环境色密度，保留高光和黑位细节，形成整体低调氛围 |

名称不提供参数。若当前图缺少相应可靠区域或颜色证据，局部目标必须为零或降级，不能用场景标签补写。

## 首要标杆检查

秋季道路同源原图只用于首轮工程验收，不向生产推理提供目标图或反求答案。真机导出后检查：道路是否明显但安全地压暗；黄叶是否相对环境更明确；绿色是否克制；天空是否冷灰柔和；白车与建筑是否中性；是否出现死黑、色偏或蒙版边缘。

## 硬失败

以下任一项出现即失败：与原图差异极小；仅整体变亮/变暗；统一冷色覆盖；中性色损伤；暗部死黑；局部边缘明显；人物真实性受损；假 HDR/AI 感；D/E1/E2 实际像素高度相似；真机全分辨率导出无明显变化。

候选差异使用 `PT-AESTHETIC-010` 的真实 Core Image 两两差异门。差异通过不等于好看；技术质量、目标合理性和人工审美继续分别记录。

## 分区颜色表达（PT-AESTHETIC-012）

- 暗部、中间调和高光必须拥有独立颜色目标；不得用统一降低色温替代。
- 中间调冷灰只作用于当前照片测量支持的环境关系，并从受保护亮部中性色蒙版中扣除。
- 暖色重点优先通过当前图已存在的橙/黄色域 HSL 建立；高光暖色只能是弱辅助，避免白车和白墙染黄。
- 阴天低色度天空禁止自动增蓝，但不能因此把所有暗部/中间调色彩关系压回零。
- 当前全局分级不能排除人物蒙版；检测到人物时必须关闭该新分级，直到实现源图相对的人物/肤色回填并完成真机像素验证。
- 任何 Windows 投影只能证明参数方向与大致表达能力；真实 Core Image 像素和摄影审美必须分别验收。
